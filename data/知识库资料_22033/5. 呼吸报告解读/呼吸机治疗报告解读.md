### 1.1 【治疗设置】核心参数及解读
| 参数名称               | 解读要点                                                                 |
|------------------------|--------------------------------------------------------------------------|
| 模式                   | 显示当前机器使用的通气模式（如CPAP、AUTO CPAP、S/T等），需确认与患者病情适配（如OSA选CPAP/AUTO CPAP，COPD选S/T） |
| 压力                   | 显示当前设置的治疗压力值（单位：cmH₂O），需匹配临床压力滴定结果，确保有效打开气道且患者耐受 |
| COMF设置               | 显示压力释放档位（如1-3档），档位越高呼气时压力下降越明显，影响患者舒适度 |
| 爬坡时间               | 显示从初始低压升至治疗压力的时间（如0-45分钟），时间越长初始适应越平缓 |
| 爬坡压力               | 显示爬坡阶段的初始压力值（低于治疗压力），避免开机高压冲击 |
| 加湿器档位             | 显示湿化器加热档位（如1-7档），档位越高湿化越强，需结合痰液性状调整（如浓痰调高） |
| 加温呼吸管路档位       | 显示加温管路加热档位（如1-3档），确保气流温度稳定（31-37℃），避免冷刺激气道 |

### 2.1 【治疗时长】核心指标及意义
| 指标名称               | 定义与临床意义                                                           |
|------------------------|--------------------------------------------------------------------------|
| 本次治疗时间           | 报告生成当天的具体治疗日期，明确单次治疗的时间节点                        |
| 报告天数               | 本次报告覆盖的总天数（如7天、30天），反映观察周期长度                    |
| 治疗天数               | 报告周期内实际使用呼吸机的天数，体现治疗连续性                          |
| 日治疗＞4小时天数      | 报告周期内每日使用时长≥4小时的天数，是判断治疗有效的关键（临床推荐每日≥4小时） |
| 日治疗＜4小时天数      | 报告周期内每日使用时长＜4小时的天数，时长不足可能影响疗效（需排查不耐受、设备故障等原因） |
| 未治疗天数             | 报告周期内完全未使用的天数，需了解未使用原因（如不适、忘记等）            |
| ＞4小时天数占比         | （日治疗＞4小时天数/报告天数）×100%，占比越高治疗依从性越好（理想＞80%） |
| 最大/最小日治疗时间    | 报告周期内单日最长/最短治疗时长，反映每日使用的波动情况                  |
| 治疗总时长             | 报告周期内所有治疗天数的时长总和，体现整体治疗投入                        |
| 平均治疗时长           | 治疗总时长/治疗天数，反映每日平均使用水平（理想≥4小时）                  |

### 3.1 【治疗分析】压力相关指标
| 指标名称               | 定义与临床意义                                                           |
|------------------------|--------------------------------------------------------------------------|
| 平均有效治疗压力       | 报告周期内实时治疗压力的平均值，需接近临床滴定压力，过高可能不耐受，过低可能无效 |
| 90th有效治疗压力       | 治疗过程中（＞10分钟）90%时间内的压力均低于该值，反映压力稳定性（波动越小越优） |
| 95th有效治疗压力       | 治疗过程中（＞10分钟）95%时间内的压力均低于该值，辅助判断压力是否过高（若接近最大值需警惕） |
| 最大有效治疗压力       | 报告周期内出现的最高治疗压力，需确认是否在安全范围（未超机器压力上限，患者无不适） |
---
### 3.2 【治疗分析】漏气相关指标
| 指标名称               | 定义与临床意义                                                           |
|------------------------|--------------------------------------------------------------------------|
| 平均漏气量             | 报告周期内实时漏气量的平均值，正常范围因面罩类型而异（鼻罩＜20LPM，口鼻罩＜30LPM），过高需检查面罩佩戴/管路破损 |
| 大量漏气时间           | 报告周期内“大量漏气”的日均时长（大量漏气定义：流量≥70LPM或进入电机保护状态，持续1.5分钟），过长需排查漏气原因（如面罩尺寸不合适、管路接口松动） |
---
### 3.3 【治疗分析】呼吸事件相关指标（核心疗效指标）
| 指标名称               | 定义与临床意义（单位：次/小时，仅统计单次治疗＞10分钟的数据）             |
|------------------------|--------------------------------------------------------------------------|
| 鼾症次数               | 报告周期内累计鼾症次数，次数越少说明气道通畅度越好                        |
| AHI（呼吸暂停低通气指数）| 阻塞性呼吸暂停+低通气次数的总和/累计治疗时间，是核心疗效指标：<5次/小时为治疗有效，5-15次/小时需调整压力，＞15次/小时提示治疗无效 |
| AH（呼吸暂停指数）      | 累计呼吸暂停次数/累计治疗时间，反映纯呼吸暂停的严重程度                    |
| HI（低通气指数）        | 累计低通气次数/累计治疗时间，反映气道部分阻塞的严重程度                    |
| OAI（阻塞性呼吸暂停指数）| 累计阻塞性呼吸暂停次数/累计治疗时间，OSA患者需关注，正常＜5次/小时        |
| CAI（中枢性呼吸暂停指数）| 累计中枢性呼吸暂停次数/累计治疗时间，正常＜5次/小时，过高需排查中枢性疾病 |
---
### 4.1 【治疗总结】核心内容与使用建议
- 核心内容：由临床医生结合患者的治疗设置、时长、呼吸事件指标（如AHI、漏气量）填写，包含疗效评估（有效/需调整/无效）和具体建议
- 关键使用建议：
  1. 若AHI＜5次/小时、日均治疗≥4小时、漏气量正常：维持当前设置，继续规律使用
  2. 若AHI＞5次/小时：需重新评估压力设置（如Auto CPAP可调高压力范围，手动模式需重新滴定）
  3. 若日均治疗＜4小时：需排查原因（如面罩不适可更换类型，压力过高可调整COMF档位或爬坡时间）
  4. 若大量漏气时间过长：检查面罩佩戴是否贴合、管路是否破损，必要时更换面罩尺寸/管路
