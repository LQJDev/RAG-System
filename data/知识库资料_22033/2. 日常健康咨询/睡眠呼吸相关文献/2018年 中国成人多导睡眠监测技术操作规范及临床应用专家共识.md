### 1.1 【PSG基础】核心定义与监测参数
#### 1.1.1 定义
- 多导睡眠监测（PSG）：在睡眠监测室中通过多导睡眠仪，同步采集、记录和分析人体睡眠期间生理信号的检查技术，最终形成多导睡眠图（polysomnogram），是睡眠疾病诊断的“金标准”
#### 1.1.2 核心监测参数（必选+可选）
| 参数类别       | 必选参数                          | 可选参数                          |
|----------------|-----------------------------------|-----------------------------------|
| 脑电相关       | 脑电图（EEG）、眼动电图（EOG）、颏肌电图（EMG） | 额外脑电图导联（如颞叶导联）        |
| 呼吸相关       | 口鼻温度传感器、鼻压力传感器、胸腹呼吸带、脉搏氧饱和度（SpO₂）、鼾声 | 呼气末二氧化碳分压（PETCO₂）、经皮二氧化碳分压（TcCO₂）、食管压力、食管pH值 |
| 心脏相关       | 单导联心电图（ECG）               | 多导联心电图、心率变异性分析        |
| 运动相关       | 双下肢胫前肌电图                  | 视音频监测、体动记录仪（actigraph）  |
| 其他           | 体位                              | 阴茎勃起功能监测（扣带张力测定）、三维加速传感器 |
### 1.2 【PSG应用】临床适应证（按疾病类型分类）
#### 1.2.1 睡眠呼吸障碍（核心适应证）
- 适用场景：
  1. 阻塞性睡眠呼吸暂停（OSA）、中枢性睡眠呼吸暂停（CSA）的诊断，明确呼吸事件类型（阻塞型/中枢型/混合型）
  2. 睡眠呼吸障碍与其他睡眠疾病（如失眠、异态睡眠）的鉴别诊断
  3. 睡眠相关低氧性疾病（如肥胖低通气综合征）的评估
  4. 睡眠呼吸障碍治疗效果监测（如CPAP治疗后症状复发、体重显著变化时）
  5. 家庭睡眠监测（HST）结果阴性但临床高度怀疑睡眠呼吸障碍的患者
#### 1.2.2 发作性睡病与特发性睡眠增多
- 适用场景：
  1. 发作性睡病的诊断（需结合多次睡眠潜伏期测试（MSLT），MSLT前需完成PSG）
  2. 特发性睡眠增多的评估，排除其他睡眠障碍（如睡眠呼吸暂停、周期性肢体运动障碍）
#### 1.2.3 异态睡眠与睡眠期癫痫
- 适用场景：
  1. 明确夜间发作性事件类型（如睡行症、夜惊、睡眠期癫痫、肌张力障碍）
  2. 临床症状不典型、治疗效果差或可能对自身/他人造成伤害的患者（需全程视音频监测+额外脑电图导联）
#### 1.2.4 睡眠相关运动障碍
- 适用场景：
  1. 周期性肢体运动障碍（PLMD）的诊断与严重程度评估
  2. 不宁腿综合征（RLS）、快速眼球运动睡眠期行为紊乱（RBD）的鉴别诊断
#### 1.2.5 失眠与昼夜节律失调
- 适用场景：
  1. 临床症状不典型或治疗效果欠佳的失眠患者，明确是否合并睡眠呼吸障碍、PLMD等共病
  2. 昼夜节律失调性睡眠觉醒障碍的评估，排除其他睡眠障碍（可联合体动记录仪）
#### 1.2.6 精神疾病相关睡眠障碍
- 适用场景：
  1. 精神疾病（如抑郁症、精神分裂症）相关睡眠障碍的治疗效果评估
  2. 排除睡眠呼吸障碍、RLS及药物（如镇静催眠药）导致的睡眠障碍

### 2.1 【PSG操作】核心参数监测规范
#### 2.1.1 脑电图（EEG）监测
- 电极放置：遵循国际10-20系统，推荐导联为C3-M2、F3-M2、O1-M2（或C4-M1、F4-M1、O2-M2）；可接受导联为Fz-Cz、Cz-Oz、C4-M1
- 参考电极：放置于Cz位置；接地电极：放置于Fpz位置及附近
- 备份电极：电极故障时，可用Fpz代替Fz、C3代替Cz/C4、O1代替Oz、M2代替M1
- 阻抗要求：≤5kΩ，出现伪迹需重新检测
#### 2.1.2 眼动电图（EOG）监测
- 电极放置：E1（左眼外眦向外向下1cm）、E2（右眼外眦向外向上1cm）
- 导联设置：推荐E1-M2、E2-M2记录，监测水平/垂直眼动，区分清醒期与REM睡眠期
#### 2.1.3 颏肌电图（EMG）监测
- 电极放置：Chin1（下颌骨前缘下2cm，中线左旁开2cm）、Chin2（同Chin1，右旁开2cm），参考电极ChinZ（下颌骨前缘中线上1cm）
- 导联设置：推荐Chin1-ChinZ或Chin2-ChinZ，评估肌电张力（如REM睡眠期肌电抑制）
#### 2.1.4 呼吸相关监测
| 监测项目       | 操作规范                          | 核心作用                          |
|----------------|-----------------------------------|-----------------------------------|
| 口鼻气流       | 口鼻温度传感器（置于鼻孔+口唇上方）+鼻压力传感器（监测气流变化），同步记录 | 识别呼吸暂停/低通气                |
| 呼吸努力       | 胸腹呼吸带（胸带：腋下乳头水平；腹带：脐水平），采用呼吸感应体积描记技术 | 区分阻塞型/中枢型呼吸事件          |
| 脉搏氧饱和度   | 指端/耳垂传感器（优先无名指），采样频率25Hz | 评估低氧程度（如氧减指数ODI）      |
| 鼾声           | 麦克风置于颈部或距离口鼻30cm处，记录鼾声强度与频率 | 辅助判断上气道阻塞                |
#### 2.1.5 其他参数监测
- 心电图（ECG）：单导联（负极右锁骨下，正极第6/7肋间），监测心率及心律失常
- 下肢EMG：电极置于双下肢胫前肌（间距2-3cm），监测肢体运动（如周期性肢体运动）
- 体位：三维加速传感器置于剑突处，记录仰卧、侧卧、俯卧位，分析体位对睡眠事件的影响
- 视音频：与EEG、EOG等同步记录，观察夜间行为（如异态睡眠、癫痫发作）
### 2.2 【PSG操作】技术与数据规范
#### 2.2.1 设备参数设置
| 采集参数       | 采样频率（Hz） | 滤波设置                          |
|----------------|----------------|-----------------------------------|
| 脑电/眼动/肌电/心电 | 500            | 高通0.3-1Hz，低通35-70Hz          |
| 口鼻温度/鼻压力/胸腹运动 | 100        | 高通0.1-0.3Hz，低通15-30Hz        |
| 脉搏氧饱和度/经皮二氧化碳 | 25        | 无特殊滤波                        |
| 鼾声           | 500            | 高通100Hz，低通3000Hz             |
- 数字分辨率：最低12 bits，确保信号精度
#### 2.2.2 定标与监测流程
1. 机械定标：定期校准设备采样频率、滤波设置，数字PSG无需每次监测定标
2. 电极安放：按标准位置粘贴，确保接触良好（皮肤清洁后用导电膏）
3. 生物定标（必做）：监测前/后执行，通过指令动作验证设备正常（表1）
4. 监测启动：获取稳定信号后开始，期间定时检测电极阻抗，记录患者异常行为
5. 监测结束：患者起床或达到监测时长（≥7小时）后停止，标记最后一帧睡眠分期
表1 生物定标指令及观察内容
| 指令动作                          | 观察通道                          | 预期效应                          |
|-----------------------------------|-----------------------------------|-----------------------------------|
| 闭眼30s（放松仰卧）               | 脑电、眼动                        | 脑电枕区出现α节律（8-13Hz）        |
| 睁眼30s（直视前方）               | 脑电、眼动                        | α节律减弱/消失，眼动出现阅读眼动/眨眼 |
| 眼球上下左右各看5次（头不动）     | 眼动                              | 眼动导联出现水平/垂直眼动波         |
| 缓慢眨眼5次                       | 眼动                              | 眼动导联出现眨眼波                 |
| 咬牙3次                           | 颏肌电                            | 颏肌电波幅显著升高                 |
| 模拟鼾声5次                       | 鼾声通道                          | 鼾声信号波幅升高                   |
| 正常呼吸5s                        | 口鼻气流、胸腹运动                | 气流与呼吸努力同步                 |
| 屏气5s                            | 口鼻气流、胸腹运动                | 气流信号消失，胸腹运动增强          |
| 活动足趾5次                       | 下肢肌电                          | 下肢肌电波幅升高                   |

### 3.1 【睡眠分期】核心依据与波形识别
#### 3.1.1 分期核心依据
- 主要指标：脑电图（脑电波类型）、眼动电图（眼动模式）、颏肌电图（肌电张力）
- 关键脑电波（表2）：
表2 睡眠分期关键脑电波
| 脑电波名称       | 频率范围       | 出现睡眠期                          | 核心作用                          |
|------------------|----------------|-----------------------------------|-----------------------------------|
| α节律           | 8-13Hz         | 清醒期（闭眼）                     | 区分清醒与睡眠                     |
| 低波幅混合频率波 | 2-16Hz         | N1期                              | N1期主要波形                      |
| 顶尖波           | 负向尖波（100-300ms） | N1期                              | N1期标志性波形                    |
| 睡眠纺锤波       | 11-16Hz（持续0.5-1s） | N2期                              | N2期标志性波形                    |
| K复合波          | 负向慢波+正向波 | N2期                              | N2期标志性波形                    |
| δ波             | 0.5-2Hz（波幅≥75μV） | N3期                              | N3期主要波形（占比≥20%为N3期）     |
| 锯齿波           | 2-6Hz          | REM期                              | REM期辅助识别                      |
#### 3.1.2 睡眠分期标准（按AASM规则）
| 睡眠期       | 脑电图特征                          | 眼动电图特征                          | 颏肌电图特征                          |
|--------------|-----------------------------------|-----------------------------------|-----------------------------------|
| 清醒期（W）  | 睁眼：低波幅混合波（β波+α波）；闭眼：枕区α节律占比＞50% | 睁眼：阅读眼动/眨眼；闭眼：慢速眼动 | 波幅多变，高于睡眠期                |
| N1期         | 低波幅混合波占比＞50%，可出现顶尖波 | 慢速眼动                          | 波幅较清醒期降低                  |
| N2期         | 出现睡眠纺锤波和/或K复合波          | 无明显眼动，偶见慢速眼动            | 波幅多变，低于清醒期                |
| N3期         | δ波占比≥20%（0.5-2Hz，≥75μV）     | 无眼动                            | 波幅低于N2期，接近REM期            |
| REM期        | 低波幅混合波，可出现锯齿波          | 快速眼球运动（规则、陡峭）          | 张力显著降低，为记录最低水平        |
### 3.2 【睡眠分期】特殊情况处理
#### 3.2.1 大体动（MBM）
- 定义：身体活动导致EEG受EMG伪迹干扰，无法识别脑电波
- 处理：暂不分期，标记“MBM”，待信号稳定后重新评估
#### 3.2.2 唤醒（Arousal）
- 非REM睡眠唤醒：脑电频率突然改变（出现α波、θ波或＞16Hz波），持续≥3s，之前有≥10s稳定睡眠
- REM睡眠唤醒：满足脑电频率变化，同时颏肌电增高≥1s
- 核心作用：评估睡眠连续性，唤醒次数增多提示睡眠质量差

### 4.1 【异常事件】呼吸相关事件
#### 4.1.1 呼吸暂停
- 定义：口鼻温度传感器气流较基线下降≥90%，持续≥10s
- 分类：
  1. 阻塞型：气流缺失期间呼吸努力持续存在/增强
  2. 中枢型：气流缺失期间呼吸努力消失
  3. 混合型：气流缺失初期呼吸努力消失，后期恢复
#### 4.1.2 低通气
- 定义：鼻压力传感器气流较基线下降≥30%，持续≥10s，伴SpO₂较基线下降≥3%或微觉醒
#### 4.1.3 呼吸努力相关觉醒（RERA）
- 定义：持续≥10s的呼吸事件，气流波形变扁平（提示上气道阻力增加），不满足呼吸暂停/低通气标准，但伴随微觉醒
#### 4.1.4 脉搏氧饱和度降低
- 定义：较呼吸事件前SpO₂下降≥3%，评估低氧严重程度（如ODI）
### 4.2 【异常事件】心脏相关事件
| 事件类型               | 定义标准                                                                 |
|------------------------|--------------------------------------------------------------------------|
| 窦性心动过速           | 心率≥90次/分钟，持续≥30s                                                 |
| 窦性心动过缓           | 心率≤40次/分钟，持续≥30s                                                 |
| 心脏停搏               | 心电图无QRS波群，持续≥3s                                                 |
| 宽复合波心动过速       | QRS波时限≥120ms，心率≥100次/分钟                                         |
| 窄复合波心动过速       | QRS波时限＜120ms，心率≥100次/分钟                                         |
| 心房颤动               | 心电图无正常P波，代之以形态/时限不等的f波，RR间期绝对不规则                 |
### 4.3 【异常事件】肢体运动异常
#### 4.3.1 周期性肢体运动（PLM）
- 定义：连续出现4次及以上肢体运动，相邻运动起点间隔5-90s
- 睡眠中周期性肢体运动（PLMS）：仅发生于睡眠期，需计算PLMS指数（次/小时）
#### 4.3.2 REM睡眠期肌电异常
- REM睡眠期持续肌电活动：1帧REM期中，颏肌电波幅高于NREM期最小波幅的时间＞50%
- REM睡眠期阵发性肌电活动：1帧REM期中，每3秒1小帧，5小帧出现0.1-5.0s、波幅较基础EMG高≥4倍的阵发性肌电活动

### 5.1 【PSG报告】常规内容（必含）
#### 5.1.1 基础信息
- 患者信息：姓名、性别、联系方式、身高、体重、BMI、颈围、腰围、血压
- 检查信息：检查日期、目的、电极放置方法、记录参数、判读依据、技师/医师签名
#### 5.1.2 睡眠结构参数（核心指标）
| 参数名称               | 定义与计算方式                                                           |
|------------------------|--------------------------------------------------------------------------|
| 关灯时间/开灯时间       | 关闭灯光嘱患者入睡时间/患者醒来不再入睡时间                                |
| 总记录时间             | 关灯至开灯的时长                                                          |
| 睡眠潜伏期             | 关灯至出现第一帧睡眠期的时间（目标＜30min）                                |
| 总睡眠时间             | 各睡眠期（N1+N2+N3+REM）累积时长                                          |
| 睡眠效率               | （总睡眠时间/总记录时间）×100%（目标≥85%）                                |
| 各睡眠期比例           | 各睡眠期时长/总睡眠时间×100%（正常：N1 5%-10%，N2 45%-55%，N3 15%-25%，REM 20%-25%） |
| 唤醒次数/唤醒指数       | 睡眠期内唤醒总次数/唤醒次数/总睡眠时间（次/小时，目标＜5次/小时）            |
#### 5.1.3 呼吸相关参数
- 呼吸事件总次数：呼吸暂停+低通气+RERA次数
- 睡眠呼吸暂停低通气指数（AHI）：（呼吸暂停+低通气次数）/总睡眠时间（次/小时）
- 氧饱和度指标：平均SpO₂、最低SpO₂、SpO₂＜88%/90%累积时间、氧减指数（ODI）
- 呼吸暂停分类：阻塞型、中枢型、混合型次数及占比
#### 5.1.4 其他参数
- 脑电图：基础脑电波类型，是否存在异常脑电活动（如棘波、尖波）
- 心脏参数：清醒/睡眠期最快/最慢/平均心率，心律失常类型及持续时间
- 肢体运动：PLMS次数、PLMS指数
#### 5.1.5 诊断小结
- 睡眠结构评估：是否存在睡眠结构紊乱（如N3期减少、REM期延迟）
- 异常事件诊断：如OSA（分度）、PLMD、异态睡眠等
- 临床建议：进一步检查（如MSLT）、治疗方案（如CPAP）
### 5.2 【PSG报告】质量控制与注意事项
- 质量评估：记录技师需备注监测过程中患者配合度、信号质量、异常干预（如调整电极）
- 数据完整性：确保总睡眠时间≥7小时，关键参数（如AHI、SpO₂）无缺失
- 签字确认：需经睡眠监测室医师复核并签字，确保判读准确性
